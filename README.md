# SandyOS — Portfolio personal

Portafolio de Sandy Solis inspirado en una interfaz de escritorio/terminal tipo Linux.

## Estructura

- `index.html` — estructura de la página
- `styles.css` — diseño, responsive y animaciones
- `script.js` — navegación, reloj y pequeñas interacciones
- `assets/profile.jpg` — foto de perfil

## Cómo verlo

Abre `index.html` en tu navegador.

## Antes de publicarlo

1. Cambia el correo de `index.html`.
2. Agrega tus enlaces reales de GitHub y LinkedIn.
3. Reemplaza los botones de proyectos por tus repositorios/demos.
4. Si quieres, agrega capturas de cada proyecto dentro de `assets/`.

## GitHub Pages

Sube estos archivos a un repositorio de GitHub y activa:
Settings → Pages → Deploy from a branch → `main` / root.
